PDFDrop is a fast PDF editor and toolkit for Windows. Everything happens on your PC: your documents are never uploaded.

EDIT ANY PDF

## runFullTrust justification
PDFDrop is a desktop (Win32) app written in Python with a Tk user interface, packaged as MSIX. runFullTrust is required to run its bundled Python runtime (pythonw.exe) as a full-trust desktop process. It opens the PDF and image files the user chooses, drops on its window or shares with it, edits or converts them locally with the MuPDF library, and saves the results where the user chooses. It does not install drivers or services, does not run in the background, and makes no network connections other than the Windows Store licence check.
